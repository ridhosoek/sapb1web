5. **Selesai** berarti Claude menulis diff/ringkasan/test dan status `SIAP DIREVIEW`; Co-Product Owner melakukan review independen dan mengisi `TERVERIFIKASI LOKAL`, `PERLU REVISI`, atau `TERBLOKIR`. 6. Jangan mencatat password, cookie sesi, token, payload sensitif, atau data personal pada file ini. MySQL production hanya `SELECT`; SAP production hanya GET/read-only sampai ada otorisasi eksplisit lain. Tidak ada commit, push ke `main`, atau deploy sebagai akibat otomatis dari handoff ini.
