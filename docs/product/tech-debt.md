Pembaruan: 2026-11-06. Dokumen ini adalah backlog berbasis inspeksi source code dan pembacaan `SELECT` pada MySQL portal. Status SAP terkini belum diperiksa langsung melalui Service Layer. Prioritas P0 berarti risiko integritas transaksi atau isolasi akses; P1 berarti hambatan operasional atau salah status; P2 berarti ketidaksesuaian dokumentasi. ## Urutan delivery yang disarankan

1. TD-03 selesai di kode lokal; verifikasi workflow portal dan perilaku MySQL sebelum deploy.
2. TD-04 selesai di kode lokal; berikutnya kebijakan tanggal GI pada `business-process-register.md`.
3. TD-01 dan TD-02 sesudah kontrak GET/metadata SAP terbukti. TD-05 menyusul desain idempotency per penerimaan GRPO dan pemeriksaan open quantity per line.
4. TD-06 menjadi bukti UAT lintas paket; TD-07 diperbarui saat perilaku berubah. Instruksi per paket ada di `docs/agent-handoff/claude-code-delivery-plan.md`.

Setiap perubahan transaksi harus menunjukkan hasil test, dampak deployment, dan bagian yang belum terverifikasi di SAP. `SAP_ERROR` tidak sama dengan `POSTING_UNKNOWN`; hasil POST ambigu harus direkonsiliasi sebelum retry (`docs/application/architecture.md:91-99`).
